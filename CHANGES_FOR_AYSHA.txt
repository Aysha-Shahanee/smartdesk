2. THE NEW ARCHITECTURE (what the code looks like now)
--------------------------------------------------------------------------------
TIMEZONE
  - ALL timestamps are ISO-8601 STRINGS in Asia/Colombo (+05:30),
    e.g. "2026-06-11T14:30:00+05:30". NOT DateTime columns, NOT UTC.
  - Configurable via TIMEZONE in .env. Core helpers: backend/app/core/time.py

IDE LAYER (renamed from vscode)
  - Table:    ide_sessions        (was vscode_sessions)
  - Endpoint: POST /api/v1/ingest/ide/event
              (/api/v1/ingest/vscode/event still works as a deprecated alias)
  - New fields: ide_name (vscode/antigravity/cursor...), parent_process_id,
    is_window_focused, collection_reason, edited_file_count,
    changed_file_count, dominant_language, languages_json, edited_files_json
  - Extension v3.1.0 (vscode-extension/): works in any VS Code-based IDE.
    Sessions SPLIT at every focus boundary:
      * IDE focused                -> normal row (is_foreground=1)
      * IDE blurred + AI editing   -> separate row (is_foreground=0,
                                      collection_reason="background_ai")
      * IDE blurred + idle 60s     -> session ends, nothing collected

FOREGROUND MATCHING
  - OS foreground PID is matched against the extension's PID *or* parent PID,
    with app-category fallback. Comet/Arc/Vivaldi recognized as browsers,
    Antigravity as IDE.

CALENDAR (new, working end-to-end)
  - One unified CalendarService (backend/app/services/calendar_service.py)
    with one-click Google OAuth (PKCE) + 15-min auto-sync job
  - Events upserted by (user_id, event_id) — re-syncs never duplicate;
    deleted events kept with status="cancelled"
  - Routes: /api/v1/calendar/{status,connect,oauth/callback,sync,disconnect,events}
  - Secrets live in backend/calendar_store/ (GITIGNORED — see section 4)

MONITORING DASHBOARD (new)
  - http://127.0.0.1:8000/dashboard/ui — live health of all 4 layers,
    totals, recent rows, calendar Connect / Sync buttons
  - JSON equivalent: GET /dashboard/overview

SESSION RELIABILITY FIXES
  - Backend restart no longer force-closes live sessions
  - Orphaned heartbeats (session closed server-side) automatically RE-OPEN
    a session instead of being dropped

MULTI-DEVICE PROVENANCE (push 2)
  - Every row now carries:
      device_id      — which machine collected it (auto-detected hostname,
                       override with DEVICE_ID= in .env)
      schema_version — currently "3" (constant in app/core/config.py)
  - Purpose: data from multiple devices can be merged later for AI training
    without ambiguity. Your machine will stamp its own hostname automatically.

CLEANUP
  - Deleted: legacy minute-window routes, plan.md, DEVELOPMENT_TODO.md,
    docs/ phase guides, old vsix builds, dead repository methods
  - README.md is now the single source of truth (architecture, setup, API
    reference, troubleshooting) — read it first

3. HOW TO PULL (step by step)
--------------------------------------------------------------------------------
  cd <your smartdesk folder>
  git checkout dev
  git stash                # only if you have uncommitted local changes
  git pull origin dev      # fast-forwards cleanly — your commits are ancestors

If you have UNPUSHED local commits beyond 298de67: stop, don't merge them —
coordinate with Jatheel first.

--------------------------------------------------------------------------------
4. REBUILD YOUR LOCAL DATABASE (MANDATORY)
--------------------------------------------------------------------------------
Your smartdesk.db was created by migrations 0002-0004 which no longer exist.
Alembic will fail with "Can't locate revision" until you start fresh:

  # close smartdesk.db in DB Browser first if you have it open!
  cd backend
  Remove-Item smartdesk.db -Force
  .\venv\Scripts\python.exe -m pip install -r requirements.txt
  .\venv\Scripts\python.exe -m alembic upgrade head
  .\venv\Scripts\python.exe -m uvicorn app.main:app --reload

(If the file refuses to delete because something holds it, fall back to
dropping all tables + VACUUM via sqlite3, then alembic upgrade head.)

--------------------------------------------------------------------------------
5. REFRESH YOUR .env
--------------------------------------------------------------------------------
Old GOOGLE_CALENDAR_* variables are obsolete (they point at the deleted
backend/calendar/ folder). Copy backend/.env.example to backend/.env.
New names:
  GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET    (option A)
  GOOGLE_CREDENTIALS_FILE=./calendar_store/credentials.json   (option B)
  TIMEZONE=Asia/Colombo
  DEVICE_ID=            (leave empty -> your hostname is auto-detected)

--------------------------------------------------------------------------------
6. CALENDAR CREDENTIALS (not in git, on purpose)
--------------------------------------------------------------------------------
backend/calendar_store/ is gitignored (it holds OAuth secrets), so you won't
receive credentials.json from the repo. Either:
  a) get credentials.json from Jatheel PRIVATELY (never commit it), put it in
     backend/calendar_store/ ;  or
  b) create your own OAuth client (type: Desktop App) in Google Cloud Console
     (steps in README section "Google Calendar")
Then open http://127.0.0.1:8000/dashboard/ui and click "Connect Google
Calendar" with YOUR Google account. Tokens are per-machine.

Note: if the OAuth app is in "Testing" status, your Gmail must be added as a
Test user, and refresh tokens expire after 7 days (publish the app for
permanent tokens).

--------------------------------------------------------------------------------
7. REINSTALL THE EXTENSIONS
--------------------------------------------------------------------------------
IDE (VS Code / Antigravity / Cursor):
  code --uninstall-extension smartdesk.smartdesk-vscode    # remove old build
  cd vscode-extension
  npx --yes @vscode/vsce package --allow-missing-repository
  code --install-extension .\smartdesk-ide-3.1.0.vsix
  # Antigravity: Extensions panel -> "..." -> Install from VSIX -> pick file
  # Then RESTART ALL IDE WINDOWS (old build keeps running until restart)

Browser (Chrome/Comet/Brave/Edge):
  chrome://extensions -> Developer mode -> Load unpacked ->
  select browser-extension/  (or click the reload icon if already added)
