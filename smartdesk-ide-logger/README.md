# SmartDesk IDE Logger

SmartDesk IDE Logger is a VS Code extension that tracks IDE activity for productivity analytics.

## Features

- File-based session tracking
- Active vs Idle time detection (AI-aware)
- Edit, save, and debug tracking
- Approximate lines and characters modified
- Terminal command tracking
- Project-level grouping
- Autosave protection

## How It Works

The extension logs activity into a local JSON file inside VS Code global storage.  
It does not send any data externally.

## Commands

- SmartDesk: Show Log Location

## Privacy

All data is stored locally on the user's machine.
No external transmission is performed.
